#深度学习总结：  
在车队培训之后，在网上了解到GoogLeNet和ResNet两种深度卷积神经网络，于是打算分别用这两种网络实现锥桶颜色识别的模型（两个网络的结构见代码注释）
GoogLeNet相比基础的深度神经网络，主要是多了Inception块，使得在同一层里能够并行地使用多种尺寸的卷积核和池化（在我的程序中使用了1X1,3X3,5X5三种卷积核），能够捕捉不同大小的特征，避免了因为手动设计网络中因参数不合理而导致训练结果不佳
ResNet主要是为了解决因为神经网络层数过深，在反向传播时出现梯度消失的问题。通过设置一个shortcut（见MyResNet中的ResidualBlock），使得输入 x 直接跨过这几层，加到输出上，变为 F(x) + x。  
从数学原理上来讲，残差块将某模块的输入 x 引到输出 y 处，使原本的梯度（y对x的导数）变成了（y+x）对x的导数，也即y对x的导数+1，这样一来梯度就不会消失了。  
然而，可能是由于我的MyResNet设计的神经网络层数很少，体现不出ResNet的优势，抑或者是结构上设计得不合理，最终训练出来的效果不如GoogLeNet，而且在模型训练的过程中性能开销也比较大，训练速度较慢。（训练和测试的结果见文件夹中截图）  
数据增强方面，在训练的过程中对训练集的图像进行一定角度的旋转和水平翻转，并且调整亮度和对比度，以增强模型的泛化能力  
总体而言，个人觉得完成这两个模型的训练在实现难度上并不是很大（因为最复杂最难的部分pytorch已经写好了，直接用就行，而且有参考代码，省去了很多工作量），最难的部分还是在网络结构的设计上，每一层的输入输出尺寸、卷积、池化之后的尺寸又是多少，很容易算错，而且这方面debug挺耗费时间的。
