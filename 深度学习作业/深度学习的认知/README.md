*选取的两个概念：卷积核和数据预处理

**卷积核：着重了解了卷积核设计的要求和技巧。

***卷积核的尺寸通常为奇数，因为这样产生明确的几何中心，方便在四周对称地填充。

***当设定填充的尺寸为（卷积核尺寸-1）/2时，可以实现输出尺寸与输入相同，方便简化后续尺寸计算

***同时，在设计卷积核尺寸时要注意平衡感受野、参数量和计算量。

***通过堆叠多个小尺寸的卷积核，可以达到和大卷积核一样的效果。比如说，一个5X5的卷积核的感受野可以用两个3X3来等效，一个7X7的卷积核的感受野可以用三个3X3来等效。然而，如果假设输入输出通道数均为C,则一个7X7的卷积核参数量为49C平方，但是三个3X3卷积核参数量为3X9C平方，也就是27C平方，相较于7X7减少将近一半，同时能够引入更多非线性的激活函数，使得拟合效果更好。

**数据预处理：着重了解了PPT中所述的yolo mosaic。

***针对图像数据的常用的预处理包括归一化、尺寸调整、随机翻转、颜色调节、随机擦除和随机裁剪等方法。在MyGoogLeNet和MyResNet中，使用了尺寸调整、随机翻转、颜色调节的方法。  

***而在Masaic之前，已经有两种重要的图像增强方法，分别是MixUp和CutMix，它们分别通过将两张图像按像素做加权混合，创造虚拟样本以及切掉一张图像的一块矩形区域，用另一张图像对应区域填充的方法，提高模型的泛化能力，让模型学习更平滑的决策边界。  

***Mosaic增强则是在CutMix的基础之上，直接将四张图像拼成一张，让混合更加高效。  

***Mosaic的具体原理和步骤如下所示：  

***1.随机选取 4 张不同的训练图像  

***2.每张图像分别进行独立的随机增强  

***3.将 4 张图拼接到一个更大的画面上，排列成 2×2 网格

***4.切割匹配输入尺寸 ：在拼成的大图上随机裁剪出一个正好等于网络输入尺寸的区域。如果裁剪区域超出某张原图的边缘，就用灰边或额外填充补齐。（以锥桶识别为例，每张图像为64X64,则拼接出128X128的图像，再随机裁切出一张64X64的图像） 

***5.同步更新边界框

**通过以上的步骤，可以极大地丰富单张图像的多样性，让模型在一轮训练中的一幅图就能够学习多样的组合。同时也提高了正则化效果，防止过拟合。
